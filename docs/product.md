# Product vision

Colblan is presented as a studio for creating and managing AI avatars. Each avatar would have its own appearance, personality, and voice, used as references to keep its content consistent.

## Proposed workflow

1. Create an avatar and define its identity and references.
2. Generate content using that identity and natural language instructions.
3. Review, select, and organize versions in a library.
4. Publish and manage content, audience, and results.

## Capabilities described

The website describes photos, videos, voice, text, campaigns, and variations; a dedicated assistant for ideas and planning; projects with multiple avatars; a calendar, scheduled publishing, an inbox, results, costs, and team permissions. It also envisions content generation projects without an avatar.

The intended audiences are creators, brands, and agencies. The site says Colblan is in development and that availability will be announced there.

These are proposed capabilities described on the website, not a guarantee of implementation or availability. This repository contains the presentation website, not a verified implementation of the complete product.
